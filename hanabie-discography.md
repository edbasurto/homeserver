# HANABIE (花冷え。) Discography Reference

This file is a reference list of HANABIE (ハナビエ / 花冷え。) song, EP, and album
titles for this repo's HANABIE-themed Docker stack naming convention. It was
compiled via web research (official Sony Music / band pages, Oricon, Natalie,
OTOTOY, Discogs, Wikipedia (EN + JA), RateYourMusic, and Japanese retailer/lyric
sites such as Tower Records, Uta-Net, and dMusic, cross-referenced against each
other) current as of early October 2026. It should still be spot-checked
against official sources (hanabie.jp, the band's Spotify/Apple Music pages) if
anything looks wrong before being treated as gospel — a couple of the newest
2026 titles and the not-yet-released "UMAMI" album in particular are worth
re-verifying closer to their release dates.

Titles are deduplicated: a song that first appeared as a standalone single and
was later folded into an album/EP (e.g. "L.C.G", "TOUSOU", "NEET GAME") is only
listed once. The list is flat and alphabetized — album/EP titles and individual
song titles are mixed together in one sequence.

Nine titles below are already in use as Docker stack names in this project
(confirmed accurate from the project baseline) and are annotated
`Title : stack-name`. The three album/EP titles noted in the baseline as
containing some of those nine tracks ("Girl's Reform Manifest", "Reborn
Superstar!", "Hot Topic") are listed as their own plain (unassigned) entries —
the container title itself is still available for future use.

Known unresolved/unverifiable items, deliberately excluded: a rumored
collaboration track with New Japan Pro-Wrestling's Tomoaki Honma (sometimes
referenced online as "we新日") could not be independently corroborated by any
primary source and was left out rather than guessed at. The "UMAMI" album
(announced for December 2, 2026) has no track listing publicly announced yet,
so only the album title itself is listed — individual track names will need to
be added once revealed.
